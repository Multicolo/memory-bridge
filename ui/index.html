📖 互通说明

AstrBot 长期记忆 ⇄ LivingMemory 官方 import/export ⇄ memory/ 目录 ⇄ DSH 会话笔记 / 行为摘要

记忆怎么走：bot 在 QQ 里聊出来的长期记忆，用官方导出接口拉到 memory/astrbot/；DSH 这边的笔记存进 memory/dsh-notes.jsonl，再用官方导入接口写回 bot，并按每个会话各存一份——因为召回时按「会话 + 人设」精确过滤。

行为怎么回传：读取本机 ~/.dsh/sessions/ 下这个工作区的会话记录（zstd 压缩的 jsonl），提炼成「用户让 DSH 做了什么 → 结果 → 涉及哪些文件」的一段话，作为一条记忆推给 bot；同一条会话内容变了才会重推，旧的那条会被替换。

DSH 侧怎么用：会话开始先 pull 一次（打开本界面也会自动拉），然后读 memory/astrbot/DIGEST.md（去重速览），不够再翻 MEMORY.md 和 recent.md；有值得记住的事就用本页「记一条」或命令行 python memory\bridge\astrbot_bridge.py note "…"，再 push。

命令行等价物：

  1. python memory\bridge\astrbot_bridge.py status | pull | push | activity | selftest
  2. python memory\bridge\astrbot_bridge.py note "一句话事实" --tags 项目,偏好
  3. 一键记忆互通.cmd --cli 打开旧的命令行流程

前提与限制：本机要能连到 6185（面板隧道）与 8899（本机面板）；隧道断了会自动请面板重开。对话记录没有逐条时间戳，只有会话最后活跃时间；只同步长期记忆、对话、人设和 DSH 行为摘要，不同步图片与文件本身。
